# BrawlTrack-first data policy

- BrawlTrack is the primary source for map/meta/composition search results.
- Brawl Planet remains a fallback when a requested BrawlTrack field or page is unavailable.
- Trophy/Ladder and Ranked contexts stay separate.
- `/pro/maps/` data is competitive/scrim data and must not be presented as ordinary Ladder or Ranked data.
- Map and brawler names should preserve the localized/source-provided display name when available.
